# رحلة في تاريخ كنيستنا (HTML / CSS / JS بدون أي Build Tools)

موقع تعليمي تفاعلي عن تاريخ الكنيسة القبطية الأرثوذكسية، بثلاث شخصيات:
الأنبا أنطونيوس، البابا كيرلس عمود الدين، وأبونا بيشوي كامل.

كل الكود HTML/CSS/JS عادي — من غير React، من غير npm، من غير أي خطوة Build.

## التشغيل

افتح `index.html` مباشرة في المتصفح، أو (أفضل، عشان الفيديوهات والـ fetch يشتغلوا صح) شغّل سيرفر محلي بسيط:

```bash
# باستخدام Python (متاح على أغلب الأجهزة)
python3 -m http.server 8000
```

وبعدين افتح `http://localhost:8000` في المتصفح.

للنشر على Vercel / Netlify / GitHub Pages: ارفع المجلد كامل زي ما هو، مفيش أي Build Step مطلوب.

## الأماكن اللي محتاجة منك تعديل

كل المحتوى موجود في ملف واحد بمعزل عن باقي الكود: `js/data.js`

### 1) الفيديوهات
كل فيديو له `videoUrl` — مسار محلي جوه `assets/videos/`، مثلًا:

```
assets/videos/antonios-1.mp4
assets/videos/antonios-2.mp4
assets/videos/antonios-3.mp4
```

حط ملفات الفيديو بتاعتك في `assets/videos/` بنفس الأسماء، أو غيّر الأسماء في `data.js`.
لو الملف مش موجود، الموقع هيعرض رسالة خطأ واضحة بدل ما يكسر.

### 2) الأسئلة
كل فيديو له مصفوفة `questions`، وحاليًا فيها أسئلة Placeholder شكلها كده:

```js
{
  question: "TODO: اكتب هنا نص السؤال الخاص بهذا الفيديو",
  options: ["TODO: اختيار 1", "TODO: اختيار 2", "TODO: اختيار 3", "TODO: اختيار 4"],
  correctAnswer: 0, // index الاختيار الصح (يبدأ من صفر)
}
```

امسح الأسئلة دي وحط أسئلتك الحقيقية بنفس الشكل. تقدر تحط من 3 إلى 5 أسئلة لكل فيديو.
لو عايز سؤال صح/غلط، حط `options: ["صح", "غلط"]` و `correctAnswer` بالـ index المناسب.

### 3) الصور
كل شخصية لها `image` — مسار محلي جوه `assets/images/`. لو الصورة مش موجودة، هيظهر أيقونة صليب بديلة تلقائيًا بدل ما يتكسر الـ Layout.

### 4) ملفات الـ Comic Book (PDF)
كل شخصية لها `pdf` — مسار محلي جوه `assets/pdfs/`:

```
assets/pdfs/anba-antonios-comic.pdf
assets/pdfs/pope-kyrillos-comic.pdf
assets/pdfs/fr-bishoy-kamel-comic.pdf
```

## هيكل المشروع

```
index.html          # الصفحة الرئيسية (Hero + طريقة الاستخدام + رحلتك التعليمية)
saint.html           # قالب صفحة الشخصية — بيقرأ ?id= من الرابط ويبني المحتوى بالـ JS
css/
└── styles.css       # كل التصميم — متغيرات الألوان والخطوط + كل الـ Components
js/
├── data.js          # كل المحتوى (الشخصيات، الفيديوهات، الأسئلة) — عدّل هنا فقط
├── progress.js       # حفظ التقدم في localStorage
├── navbar.js         # فتح/قفل قائمة الموبايل
├── home.js           # بناء كروت الشخصيات في الصفحة الرئيسية
└── saint.js          # كل منطق صفحة الشخصية: الفيديو → الأسئلة → الفيديو التالي → الإنجاز
assets/
├── videos/
├── images/
└── pdfs/
```

## إضافة شخصية جديدة

انسخ أي عنصر (object) موجود جوه `js/data.js` وغيّر البيانات، وضيف رابط ليها في الـ Navbar
جوه `index.html` و `saint.html` (سطرين HTML بس)، وهتشتغل تلقائيًا بنفس المنطق من غير أي
تعديل في `saint.js`.

## ملاحظات تقنية

- صفحة الشخصية واحدة بس (`saint.html`) وبتقرأ رقم الشخصية من الرابط، مثلًا:
  `saint.html?id=antonios` — فمفيش تكرار كود بين الشخصيات التلاتة.
- تقدم المستخدم (آخر فيديو وصله، والـ Scores) بيتحفظ في `localStorage`، فلو قفل المتصفح ورجع هيكمل من مكانه.
- لو الـ localStorage مش متاح (Private Browsing مثلًا)، الموقع بيشتغل عادي لكن من غير حفظ تقدم، وبيظهر تنبيه بسيط.
- الموقع Static بالكامل، من غير أي Backend، ومن غير أي مكتبات خارجية (JS عادي 100%).
